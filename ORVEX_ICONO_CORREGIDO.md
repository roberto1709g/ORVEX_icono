# ORVEX 1.5.6 — Icono de aplicación

Se configuró el icono de lanzamiento ORVEX en AndroidManifest.xml mediante `android:icon` y `android:roundIcon`, con recursos para varias densidades y un icono adaptativo para Android 8.0 o posterior.

Para ver el icono en el teléfono, vuelve a compilar la APK e instala esa nueva APK. Este ZIP contiene el proyecto fuente; no es una APK compilada.
